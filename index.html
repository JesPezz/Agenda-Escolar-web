Agenda Escolar

Agenda y control de asistencia para primaria (3.º grado, grupo A).

Qué hace esta aplicación

Agenda Escolar es una herramienta de uso docente para llevar el control de un grupo de primaria. Lleva el padrón de alumnos (nombre, CURP, fecha de nacimiento, dirección y teléfono del tutor), la asistencia diaria, las calificaciones por periodo, las tareas y lecturas asignadas, el horario, el expediente de cada alumno y el calendario escolar oficial. Se distribuye en dos versiones: una aplicación de escritorio para Windows y una aplicación para Android.

Todos los datos se guardan únicamente en el equipo donde se usa la aplicación y, si la persona docente lo activa, se copian a un solo archivo (agenda_datos.json) dentro de la cuenta de Google Drive de esa misma persona docente, para poder abrir los mismos datos desde el móvil. La sincronización solo puede crear, leer y modificar ese archivo: la aplicación nunca toca otro contenido de la cuenta.

Datos y permisos

La aplicación solicita un único permiso de Google: drive.file, que la limita exclusivamente a los archivos que ella misma crea. No accede a otros archivos del Drive, ni al correo, ni a contactos, ni a la ubicación.
